# Hotel Booking App - React Native

A comprehensive hotel booking mobile application built with React Native, featuring user authentication, hotel listings, booking flow, reviews, and third-party API integrations.

## Features

### Section A: Mobile UI Implementation
- **Onboarding Screens**: Multi-screen tutorial flow for new users
- **Authentication**: Sign up, sign in, and password reset with validation
- **Explore Page**: Hotel listings with search, filtering, and sorting
- **Booking Flow**: Complete booking process with date selection and validation
- **Reviews System**: Add and view hotel reviews with star ratings
- **Profile Page**: User profile with booking history and edit functionality

### Section B: Backend Integration
- **Firebase Configuration**: Secure setup with environment variables
- **Firebase Authentication**: Email/password auth with state persistence
- **Cloud Firestore**: Real-time data storage for users, bookings, and reviews
- **Third-Party APIs**: 
  - Fake Store API for recommended hotels and deals
  - OpenWeatherMap API for weather information

## Tech Stack

- React Native
- Firebase Authentication
- Cloud Firestore
- React Navigation
- AsyncStorage
- Axios for API calls

## Setup Instructions

### Prerequisites
- Node.js and npm
- React Native CLI
- Android Studio / Xcode (for emulators)
- Firebase account
